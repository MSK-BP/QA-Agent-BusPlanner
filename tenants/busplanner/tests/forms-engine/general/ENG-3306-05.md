## Steps
1. Read `ConditionTests.Performance_TenThousandCachedEvaluationsUnder100ms` in `$repo\BusPlannerUnified\BusPlanner.Tests.Unit\Forms\ConditionTests.cs`.
2. Run it 3 times: `1..3 | % { dotnet test $tp -c Release --no-build --filter "FullyQualifiedName~ConditionTests.Performance_TenThousandCachedEvaluationsUnder100ms" }`.
3. Measure independently in compiled code, in a fresh `pwsh` process with no other case running:
   ```
   Add-Type -Path $dll
   Add-Type -ReferencedAssemblies $dll, 'netstandard', 'System.Collections', 'System.Runtime' -TypeDefinition @'
   using System.Collections.Generic; using System.Diagnostics; using BusPlanner.Forms.Conditions;
   public static class QaPerf {
     public static double Run() {
       var a = new Dictionary<string, object> { { "[Q01]", "[Accident]" }, { "[Q02]", true }, { "[Q17]", 12 } };
       var s = new Dictionary<string, object> { { "Conduct_FirstReview", "SCHOOL" } };
       var ctx = new DictionaryConditionContext(a, null, s, null, null);
       var t = "([Q02]=='[Yes]' || [Q01]=='[Injury]') && {setting:Conduct_FirstReview}=='SCHOOL' && [Q17]>=12";
       if (!Condition.Evaluate(t, ctx)) throw new System.Exception("warm-up returned False");
       var sw = Stopwatch.StartNew();
       for (int i = 0; i < 10000; i++) Condition.Evaluate(t, ctx);
       sw.Stop(); return sw.Elapsed.TotalMilliseconds;
     }
   }
   '@
   $ms = 1..5 | % { [QaPerf]::Run() }; $ms; ($ms | Sort-Object)[2]
   ```
4. In pipeline `BusPlannerUnified-backend-dev` (definition 246, `pipelines/backend-deploy-dev.yml`), read with `tenants\busplanner\harness\ado.ps1` (GET only): find the build whose `sourceVersion` is PR 1902's `lastMergeCommit` and read the result of `Performance_TenThousandCachedEvaluationsUnder100ms` in its test run.

## Expected (each line must be checkable)
- E1 (step 1, cli): the test warms up with one `Condition.Evaluate` before the stopwatch starts, loops `10_000` times over `Condition.Evaluate(string, ...)` and asserts less than 100 ms.
- E2 (step 2, cli): each of the 3 runs ends with the counts Failed 0, Passed 1, Total 1.
- E3 (step 3, cli): no exception (the warm-up returned True), and the median of the 5 timings (last line) is under 100.
- E4 (step 4, cli): the build's `sourceVersion` equals PR 1902's `lastMergeCommit`, and the test's outcome is Passed (the test asserts under 100 ms).
