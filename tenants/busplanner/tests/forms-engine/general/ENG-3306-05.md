## Preconditions
- SHELL: as in ENG-3306-01 (PowerShell 7, `dotnet-qa` first on PATH, variables `$repo`, `$tp`, `$bin`, `$dll`, `$run`).
- ENG-3306-01 step 1 passed (Release build). The library DLL is at `$dll`.
- Close other heavy work on the machine. Record the CPU model and power mode in the observations.

## Steps
1. Read `ConditionTests.Performance_TenThousandCachedEvaluationsUnder100ms` in `$repo\BusPlannerUnified\BusPlanner.Tests.Unit\Forms\ConditionTests.cs`.
2. Run it 3 times: `1..3 | % { dotnet test $tp -c Release --no-build --filter "FullyQualifiedName~ConditionTests.Performance_TenThousandCachedEvaluationsUnder100ms" }`.
3. Measure independently with the built DLL:
   ```
   Add-Type -Path $dll
   $a = [Collections.Generic.Dictionary[string,object]]::new(); $a['[Q01]']='[Accident]'; $a['[Q02]']=$true; $a['[Q17]']=12
   $s = [Collections.Generic.Dictionary[string,object]]::new(); $s['Conduct_FirstReview']='SCHOOL'
   $ctx = [BusPlanner.Forms.Conditions.DictionaryConditionContext]::new($a,$null,$s,$null,$null)
   $t = "([Q02]=='[Yes]' || [Q01]=='[Injury]') && {setting:Conduct_FirstReview}=='SCHOOL' && [Q17]>=12"
   [BusPlanner.Forms.Conditions.Condition]::Evaluate($t,$ctx)
   $ms = 1..5 | % { $sw=[Diagnostics.Stopwatch]::StartNew(); for($i=0;$i -lt 10000;$i++){ [void][BusPlanner.Forms.Conditions.Condition]::Evaluate($t,$ctx) }; $sw.Stop(); $sw.Elapsed.TotalMilliseconds }
   $ms; ($ms | Sort-Object)[2]
   ```
4. Read the duration of the same test in the CI run for the merge commit of PR 1902.

## Expected (each line must be checkable)
- E1 (step 1, cli): the test warms up with one `Condition.Evaluate` before the stopwatch starts, loops `10_000` times over `Condition.Evaluate(string, ...)` and asserts less than 100 ms.
- E2 (step 2, cli): each of the 3 runs ends with the counts Failed 0, Passed 1, Total 1.
- E3 (step 3, cli): the first `Evaluate` prints `True`, and the median of the 5 timings (last line) is under 100. A median of 100 or more is Inconclusive, not Fail, because the PowerShell loop adds per-call overhead.
- E4 (step 4, cli): the CI test passed under 100 ms on the CI server. Blocked until the CI test pipeline is named.
