## Steps
1. Run `python -I "$repo\docs\forms-engine\tests\frm_condition_reference.py" "$repo\docs\forms-engine\tests\frm-condition-tests-draft-01.json"; $LASTEXITCODE`.
2. Make a shadow copy with 9 probe cases. All use context `inspection` and expect `true`:
   ```
   $src = "$repo\docs\forms-engine\tests\frm-condition-tests-draft-01.json"
   $dst = "$bin\docs\forms-engine\tests"; New-Item -ItemType Directory -Force $dst | Out-Null
   $j = Get-Content $src -Raw | ConvertFrom-Json
   $p = [ordered]@{
     P01="[Q17]=='12.0'"; P02="[Q11]=='32.50'"; P03="[Q12]==12";
     P04="[Q17]=='$([char]0x0661)$([char]0x0662)'"; P05="[Q15]<'7:45'"; P06="[Q14]<'2026-11-09T08:00'";
     P07="{setting:Max_Pressure}==35.0"; P08="[Q17]=='12`n'"; P09="[Q17]==12." }
   foreach($k in $p.Keys){ $j.cases += [pscustomobject]@{id="QA-AUTO-SK-$k"; context='inspection'; condition=$p[$k]; expected=$true; note='ENG-3306-06 parity probe'} }
   $j | ConvertTo-Json -Depth 10 | Set-Content "$dst\frm-condition-tests-draft-01.json" -Encoding utf8NoBOM
   ```
3. Run the reference on the shadow copy: `python -I "$repo\docs\forms-engine\tests\frm_condition_reference.py" "$dst\frm-condition-tests-draft-01.json"`. Record each FAIL line.
4. Run `dotnet test $tp -c Release --no-build --filter "FullyQualifiedName~ConditionSharedCasesTests.Case_MatchesTheReference" --logger "trx;LogFileName=ENG-3306-06.trx" --results-directory $run`. Record each failed ID and its message.
5. Compare the two outcomes for each probe ID.

## Notes
- Traces to the story description: "the server and the Turns app give exactly the same answer". `Condition.cs` says the Python reference breaks any tie.
- The probes need no known true answer: the oracle is "same outcome as the reference". Each targets a place where `Condition.cs` copies Python behaviour by hand: number text coercion (P01, P02, P07), number against multi-select (P03), Unicode digits (P04), ISO ordering with different lengths (P05, P06), `$` before a final newline (P08), number grammar edge (P09).
- A mismatch is a product bug in one of the two evaluators; the reference wins.
