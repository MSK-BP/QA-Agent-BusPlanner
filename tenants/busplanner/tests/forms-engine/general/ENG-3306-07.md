## Steps
1. Run `dotnet test $tp -c Release --no-build --filter "FullyQualifiedName~ConditionTests.ParseError_|FullyQualifiedName~ConditionTests.IsTrue_|FullyQualifiedName~ConditionTests.EmptyText_"`.
2. Parse the 8 error conditions from the shared file through the public API:
   ```
   Add-Type -Path $dll
   $errs = "[Q01]","[Q01]='[Yes]'","{answer:Q01}=='x'","([Q01]=='[Yes]'","[Q01]=='[Yes]' &&",'[Q01]=="[Yes]"',"!([Q01]=='[Yes]')","[Q01]=='[Yes]' and [Q02]=='[No]'"
   foreach($e in $errs){ try { [void][BusPlanner.Forms.Conditions.Condition]::Parse($e); "NO ERROR | $e" } catch { $x = $_.Exception.InnerException ?? $_.Exception; "{0} | {1} | {2} | {3}" -f $x.GetType().Name,$x.Position,$e.Length,$x.Message } }
   ```
3. Check the column rule through the public API:
   ```
   $empty = [BusPlanner.Forms.Conditions.DictionaryConditionContext]::new($null,$null,$null,$null,$null)
   [BusPlanner.Forms.Conditions.Condition]::IsTrue([NullString]::Value, $empty)
   [BusPlanner.Forms.Conditions.Condition]::IsTrue('', $empty)
   [BusPlanner.Forms.Conditions.Condition]::IsTrue("[Q01]=='[Yes]'", $empty)
   ```

## Expected (each line must be checkable)
- E1 (step 1, cli): the summary counts are Failed 0, Passed 8, Skipped 0, Total 8.
- E2 (step 2, cli): 8 lines, all `ConditionParseException`, no `NO ERROR`; the positions in order are 5, 5, 0, 15, 17, 7, 0, 15, and each message ends with `(at position <that number> in "<text>")`.
- E3 (step 2, cli): the messages start with: `a comparison needs an operator` (line 1); `unexpected text` (lines 2, 3, 6, 7, 8); `expected ')'` (line 4); `expected a value` (line 5).
- E4 (step 3, cli): `True`, `True`, `False`.

## Notes
- Sources: story Behaviour 2 (the parse exception names the position and the problem); `condition-grammar.md`: NULL or empty means "always true"; `schema-reference.md`: `condition_expression` NULL = always true.
- The shared file checks only that the 8 error cases throw, not the position. This case closes that gap.
- Positions come from the Python reference (`unexpected text at N`) for lines 2, 3, 6, 7, 8; for lines 1, 4, 5 the error is at the end of the text.
- Run steps 2 and 3 in a fresh `pwsh` process: `Add-Type` locks `$dll` for the session.
- `[NullString]::Value` is needed: PowerShell turns `$null` into `""` for a string argument.
