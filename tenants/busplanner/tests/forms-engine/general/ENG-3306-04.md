## Preconditions
- SHELL: as in ENG-3306-01. `$turns = "$env:USERPROFILE\Repos\Apps\Apps\MauiTurns\Turns\Turns.csproj"`.
- A Turns branch references `BusPlanner.Forms.Conditions` as a package or a project. The Turns repo owner supplies it (open item R10, needed by ENG-3307). QA does not edit `Turns.csproj`.
- Android: the `maui-android` workload, an Android SDK and a JDK are installed.
- iOS: a paired Mac build host with Xcode. iOS cannot build on Windows alone.

## Steps
1. Run `Select-String -Path $turns -Pattern 'Forms.Conditions'`.
2. Run `dotnet workload list`.
3. Run `dotnet build $turns -f net10.0-android -c Debug`.
4. Run `Get-ChildItem "$(Split-Path $turns)\bin\Debug\net10.0-android" -Recurse -Filter BusPlanner.Forms.Conditions.dll`.
5. Run `dotnet build $turns -f net10.0-ios -c Debug` with the Mac host paired, or get the build log for the same branch from the Turns owner's Mac.

## Expected (each line must be checkable)
- E1 (step 1, cli): a `PackageReference` or `ProjectReference` line to `BusPlanner.Forms.Conditions`, not in a comment.
- E2 (step 2, cli): `maui-android` is listed, and `maui-ios` for step 5.
- E3 (step 3, cli): `Build succeeded` with `0 Error(s)` for `net10.0-android`.
- E4 (step 4, cli): the library DLL is in the Android build output.
- E5 (step 5, cli): `Build succeeded` with `0 Error(s)` for `net10.0-ios`.
