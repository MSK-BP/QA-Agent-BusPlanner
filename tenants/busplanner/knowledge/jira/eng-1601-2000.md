### Old World Dispatch notifications (shipped in 13.2.6, ENG-1616 QA notes)
- Saving in Quick Dispatch (timeline drag, Route Management > Modify Runs, Split, Merge) sends no parent email and no app push; the "Send Run Changes" count rises and the save message says parents were not told yet (ENG-1616).
- Releasing rows in Send Run Changes is what sends; afterwards Email and App read "Sent" and the row moves to the Sent filter (ENG-1616).

## 4. Recurring defect patterns and regression-prone areas

1. **Environment and configuration pointing at the wrong thing** (most common root cause of school-opening tickets): BP Web GeoIMS settings on a wrong, similarly named database (ENG-1924), Quick refresh script restarting another GeoIMS instance (ENG-1937), GPS+ pointed at a Chipmunk tracker (ENG-1998), vehicle mappings swapped (ENG-1965), web.config culture edit reverted (ENG-1602, ENG-1938), reader needing a restart (ENG-1982, ENG-1956). Test idea: an environment-sanity checklist per client after upgrade.
2. **Future effective dates and the Database Active Date** break reports and APIs: ENG-1813, ENG-1947, ENG-1951, ENG-1962, ENG-1979 (and possibly ENG-1923). Regression set: run Student Report, transported-students reports and BPInfo StudentRide with future-dated transportation, addresses and enrollments.
3. **Silent or misleading failure**: startup swallows schema errors (ENG-1603), GeoIMS discards the failure reason (ENG-1933), WTB reader hid auth failures (ENG-1861), raw exception to the user (ENG-1860), wrong field named in the error (ENG-1859), success message with empty file (ENG-1932), upgrade marks itself done (ENG-1963), Extract-style "Completed" despite failure (pattern already noted in domain.md).
4. **Fleet purchase orders and work orders**: paged totals (ENG-1930), bulk PDF vs single PDF differences (ENG-1959, ENG-2000), unknown GUID hangs the session (ENG-1948), 0.00 unit cost after settlement (ENG-1993), status locks (ENG-1995), fuel import (ENG-1860, ENG-1969), packaging 500s (ENG-1968). Most were found by QA (Hamad Zeb), so this area has good exploratory coverage but many open defects.
5. **GPS vendor API contracts change underneath the readers**: Samsara cursor format (ENG-1607, ENG-1944), WTB auth parameters (ENG-1861), Synovia account/GUID setup (ENG-1982, ENG-1996), Geotab sensor cursor starvation (ENG-1931), Zonar scanner list (ENG-1954).
6. **Load, connections and performance at school opening**: CTSO IN-66 findings (ENG-1864..ENG-1867), STSYR port exhaustion (ENG-1997), LESA report freezes (ENG-1922, ENG-1928), Live Viewer view cost (ENG-1604), missing workflow indexes (ENG-1935), RCJTC tracker table bloat (ENG-1955), PGCPS speed (ENG-1964, ENG-1978, ENG-1991).
7. **Data isolation**: cross-database street lookup (ENG-1865) and the whole chatbot scope programme (ENG-1878..ENG-1881, ENG-1889, ENG-1917). Treat any scope leak as a security defect (ENG-1889 QA notes).
8. **Notifications delivered many times**: Dispatch intermediate saves (ENG-1616) and Delays push re-sent per chunk to users already reached (ENG-1946, same as ENG-1267).
9. **Turns scanning and multi-run transitions**: transfer site not recognised on the second run (ENG-1929, cannot reproduce), new pass IDs vanish (ENG-1958). Both need client data to reproduce.
10. **Concurrency**: GeoIMS student-update deadlocks (ENG-1934); Unified Dispatch save designed with per-run versioning and applock (ENG-1632).
